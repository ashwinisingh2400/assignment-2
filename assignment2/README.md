# Ashwini.dev - Beginner Student Portfolio

An easy, beginner-friendly multi-page student portfolio built using only **HTML5** and **CSS (Flexbox Layout Engine)** with **zero JavaScript**.

## Project Details
- **Student Name:** Ashwini
- **Goal:** Become an Android App Developer
- **Achievements:** C++, Python, Kotlin
- **Projects:** FragTracker, Notebook, Notes Maker
- **Design:** Flexbox Layout Engine only (No Grid, No JavaScript)

## Website Pages
1. [**index.html**](index.html) - Home page with hero section, introduction, and navigation cards.
2. [**about.html**](about.html) - About Me page with story, hobbies, and quick facts.
3. [**skills.html**](skills.html) - Skills page showcasing Kotlin, C++, Python, and Android Development.
4. [**projects.html**](projects.html) - Projects page featuring FragTracker, Notebook, and Notes Maker.
5. [**achievements.html**](achievements.html) - Achievements timeline with milestones in C++, Python, and Kotlin.
6. [**contact.html**](contact.html) - Contact page with a pure HTML contact form.

## Styling
- [**style.css**](style.css) - Clean and beginner-friendly stylesheet using Flexbox for all layout alignments (`display: flex`, `justify-content`, `align-items`, `flex-wrap`, `gap`).
